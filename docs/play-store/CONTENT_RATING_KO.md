# 음영 인쇄소 · 콘텐츠 등급(IARC) 설문 참고

Play Console의 콘텐츠 등급 설문은 사용자가 직접 답한다. 아래는 게임 내용에서 확인한 사실과 답변 제안이다.
등급 결과(예: 국내 게임물관리위원회 등급, PEGI/ESRB 대응 등급)는 설문 결과로 정해지며 여기서 단정하지 않는다.

| 설문 항목 | 게임 내용 | 답변 제안 |
| --- | --- | --- |
| 폭력 | 묘사 없음. 전투·부상·피 없음 | 아니요 |
| 공포·무서운 내용 | 심리 미스터리 분위기: 문서의 모순, 비어 있는 이름, 반복되는 소리, 밤의 작업실. 점프 스케어·괴물·고어 없음 | 사람 판단 필요(가벼운 공포 요소로 답할지 결정) |
| 성적 내용·노출 | 없음 | 아니요 |
| 비속어 | 없음(사람의 문학 검토로 최종 확인) | 아니요 |
| 약물·음주·흡연 | 없음(사람 확인) | 아니요 |
| 도박·모의 도박 | 없음 | 아니요 |
| 사용자 간 상호작용·채팅 | 없음(오프라인 싱글 플레이) | 아니요 |
| 위치 공유 | 없음 | 아니요 |
| 디지털 상품 구매 | 없음 | 아니요 |

공포 수위 답변은 실제 플레이를 본 사람이 정한다. 자동 검사는 문서의 표현 수위를 판단하지 않았다.

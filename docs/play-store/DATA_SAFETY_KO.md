# 음영 인쇄소 · 데이터 보안 양식과 권한 근거

Play Console "앱 콘텐츠 > 데이터 보안"에 답할 때 쓰는 근거다. 아래 사실은 빌드 검증
(`scripts/android/package_android.py`가 남기는 `android-evidence.json`)과 소스에서 확인한 것이다.
양식 제출과 최종 답변은 사용자가 한다.

## 확인된 사실

- **권한**: 매니페스트에 런타임 권한이 없다. 인터넷 권한도 없다. 엔진 내부용 서명 권한
  `com.shadowprintshop.game.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`만 있다(사용자 데이터 접근 아님).
- **네트워크**: 게임 코드에 네트워크 요청이 없다. 광고·분석·충돌 보고 SDK가 없다.
- **저장**: 진행 저장과 설정은 앱 전용 저장소(Godot `user://`)에만 쓴다. 기기 밖으로 나가지 않는다.
  앱을 지우면 함께 지워진다(`retain_data_on_uninstall=false`). 안드로이드 백업은 꺼 두었다(`allowBackup=false`).
- **계정·결제**: 로그인, 계정, 인앱 구매가 없다.

## 양식 답변 제안

| 질문 | 답 |
| --- | --- |
| 앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요? | 아니요 |
| 모든 사용자 데이터가 전송 중 암호화되나요? | 해당 없음(전송하지 않음) |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 해당 없음(수집하지 않음). 기기에서 앱을 삭제하면 저장이 지워짐 |

"수집"은 기기 밖으로 데이터를 보내는 것을 뜻한다. 기기 안에만 남는 저장은 수집이 아니다.
게임에 네트워크·광고·분석 기능을 나중에 추가하면 이 양식을 다시 작성해야 한다.

## 대상 연령

어린이를 주요 대상으로 하지 않는다(심리 미스터리 분위기). "대상 연령층"에서 13세 이상을 고르면
가족 정책(Families) 요건이 적용되지 않는다. 최종 선택은 사용자 몫이다.

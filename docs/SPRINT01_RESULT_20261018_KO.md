# C01 음영 인쇄소 스프린트 01 결과 · 2026-10-18

자동 검증과 Windows 실행까지 완료했다. 실제 게임 코드 2개 파일을 개선했으며, 인간의 플레이 평가·청취·출시 승인은 별도로 남아 있다. 기존 오디오 인증을 유지했고 엔진을 재빌드하거나 교체하지 않았다. PC 자동 종료는 하지 않았다.

1. UI/UX: CURRENT / AFTER 무료 미리보기 / TARGET을 종이·잉크 색의 제목 띠로 구분했다. 8단계 진행 표시는 조작할 수 없으며 현재 위치와 현재 퍼즐 완료만 표현한다. 선택 도장·회전, 사용 불가 도장, 주요·보조 버튼과 hover/pressed/hover_pressed/focus/disabled 상태를 정리했다. 다음 버튼의 강조는 실제 활성 상태를 따른다.
2. 화면 배치: 제목과 메뉴의 실제 글자 폭을 측정해 가로/세로 배치를 선택한다. 세로 여백을 줄여 1280×720·100% 첫 화면에 세 보드와 인쇄 버튼을 스크롤 없이 표시한다. 설정의 음량 이름·슬라이더와 글자 크기 줄을 분리했다. 125/150%에서는 세로 스크롤을 허용하며 키보드 포커스를 따라 이동한다.
3. 연출·학습 흐름: 도장 선택·회전·수동 다음 퍼즐에 0.20초 테두리 반응을 더했다. 입력·게임 상태 변경은 즉시 한 번만 일어난다. 모달, 새 동작, 장면 종료와 모션 축소에서 추가 효과를 취소한다. 기존 인쇄·Undo·완료 연출과 SFX 타이밍은 유지한다. 첫 화면에서 0↔1 반전, 무료 AFTER, 재인쇄 복원, U/Z·힌트를 설명한다. 미리보기 일치/인쇄 이력/완료에 따라 안내를 다시 계산하며, 최종 완료에는 다음 퍼즐 없음·메뉴/다시 시작·Undo를 안내한다.
4. 게임 변경 파일: `projects/first-game/game/scripts/slice_main.gd`, `projects/first-game/game/scripts/slice_board.gd`. 8개 퍼즐/해답, 상태·저장 형식, 기존 테스트·검증 기준, 하네스 소스, 기존 자산은 변경하지 않았다. 오디오와 저장 관련 12개 함수의 본문도 기준 커밋과 동일하다.

기존 Smoke, Regression, SLICE, 기계적 8,000 시퀀스/367,008 검사, 진행 명료성, 오프라인 퍼즐, UI 품질 155, 저장/설정 67, 상황별 툴팁 184 검사를 유지했다. 독립 회귀의 두 소스는 **최종 게임과 이번 스프린트 UI 중간 버전**이며 원본/패치 엔진 비교를 다시 수행한 것은 아니다.

실패와 수정도 보존했다. 첫 작업은 상태 JSON 교체의 Windows 액세스 거부로 오디오 22번째 프로세스를 시작하기 전에 중단되었다. 앞선 21회는 정상 종료했고, 상태 저장 오류는 권한 변경 없이 기존 QA→resume으로 복구했다. 두 번째 작업에서 최초 캐시 IMPORT가 `0xC0000005`로 1회 비정상 종료되어 동일 코드로 제한 재검증했고 통과했다. 이 에디터 종료 문제의 근본 원인을 해결했다고 주장하지 않는다. 세 번째 작업의 최초 모델은 미검증 배치/포커스를 이유로 blocked를 반환했다. 부모의 실제 검증에서 87/88이 확인됐고, 남은 720p 인쇄 버튼 잘림을 여백 수정으로 해결한 뒤 동일 88검사를 모두 통과했다. blocked 응답이나 실패 기록을 삭제하지 않았으며, 검증 기준도 낮추지 않았다.

## B. 향후 상품 전체 제작 — 별도 범위·사람 결정 필요

아래는 남은 제작 업무 목록이며 제품 분량·가격·일정 확정이 아니다. 12주 목표의 실현 가능성은 제작시간과 실플레이 근거로 다시 판단한다.

- [ ] 사람의 최종 게임 선정 및 제작 범위 결정. 전체 퍼즐 수/규칙/플레이시간/난이도 곡선을 실제 제작·풀이 시간으로 추정하고 검수 인력·일정·중단 조건 확정. 6개 시험 퍼즐을 완제품으로 표시하지 않음.
- [ ] 전체 퍼즐 데이터·해답·힌트·난이도·재활용 검수, 온보딩/엔딩/저장 버전 이행·충돌/복구, 설정 접근성, 긴 세션/휴면 복귀·진행 불능 검사.
- [ ] 아트 전체 세트/오디오 믹스/최종 폰트 제작과 사람 검토. 엔진/의존성/폰트/직접·생성·외주 자산 모두 상업권리·재배포·고지·계약/제작 기록 확인. unverified 항목은 상업 배포 관문을 통과하지 못함. 구매·외주·다운로드는 별도 명시적 승인 후에만.
- [ ] 한국어 원문 교정, 지원 언어 선정, 용어집·문자열 ID·복수형/줄바꿈/숫자·단축키 표기·힌트 번역 검수. 영어 등 번역은 예정이며 완료 아님. 전체 글리프와 긴 번역/150% 확대에서 모든 화면·오류 메시지 검사. 번역 계약/권리도 기록.
- [ ] Windows 목표 OS/최소·권장 사양을 실제 측정으로 결정. 배포 엔진/템플릿 버전·라이선스 고정, release 빌드·로그·저장 경로·버전 표시·백신 오탐 여부·크래시 확인. 설치 경로 공백/한글, 일반 사용자 권한, 창모드/전체화면·DPI·Alt-Tab·다중 모니터 검사.
- [ ] 별도 Windows 환경의 새 설치·업데이트·재설치·오프라인 실행·실플레이·완주·오랜 세션·저장 복원 및 이전 버전 저장 호환. 제거/재설치에도 사용자 저장을 허가 없이 지우지 않음. 테스트 PC/빌드/입력 장치/결과와 알려진 결함 기록.
- [ ] Steam 상점은 비공개 초안부터: 확정된 실제 게임 설명·지원 언어·사양·콘텐츠 분량, 직접 플레이 캡처·트레일러·캡슐·권리 고지·가격 가설·지원 연락 방식. 공식 최신 이미지 규격·필수 정보·콘텐츠/생성 자산 공개 요구의 적용 여부·검토 절차를 그때 확인. 현재 규정/규격 재조사는 하지 않았음.

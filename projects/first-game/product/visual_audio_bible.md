# PRODUCT-001 — C01 시각·오디오 제작 설계안

2026-10-12 · PENDING_HUMAN_APPROVAL. 종이/판화 2D의 소규모 시범 제작 지침이며 이미지·음원·애니메이션 구현은 없다. 상업 품질·권리·청취 결과는 미검증이다. [UI 명세](ui_ux_spec.md), [자산 목록](asset_manifest.json), [시험/출시 관문](ship_checklist.md)과 함께 검토한다.

## 종이·판화 아트 디렉션

정면 고정 2D, 따뜻한 종이 바탕과 단단한 검은 판화 실루엣. 손으로 찍은 느낌은 테두리의 작은 불균일과 주변 섬유로만 표현한다. 논리 셀의 위치·마스크·모서리는 정확하게 유지한다. 종이 얼룩이 0/1이나 미리보기의 변화로 오인되지 않게 한다. 인물·배경 원화·3D·실사 재료는 시험 범위 밖이다. 실제 음영보다 규칙 읽기가 우선이다.

작업 원본은 벡터 SVG, 게임 시범도 단순 SVG 또는 코드 도형. 종이 타일만 무손실 PNG를 제안한다. 그림 안에 번역할 문장을 굽지 않고 UI 텍스트로 분리한다. 확대용 선 두께는 720p에서 최소 2px, 포커스 3px; 픽셀 크기 변화와 필터링에 따른 경계 번짐은 실물 확인한다. 텍스처 투명도 목표 4% 이하, 보드 중앙/문자 배경에는 무늬를 두지 않는다. 장식 토글 없이도 읽을 수 있어야 한다.

## 팔레트와 기호

| 토큰 | sRGB 제안 | 용도와 색 외 표기 |
| --- | --- | --- |
| paper | #F4EBDD | 0 셀·배경, 숫자 0 |
| ink | #24211D | 본문·1 셀, 1 셀 위 숫자는 paper |
| panel | #E4D5BE | 카드 바탕, ink 제목·경계 |
| accent | #8A3F24 | 도장 강조/포커스, 이중 테두리와 화살표 |

| error | #8B2635 | 거부/저장 오류, ×+원인 문장 |

밝은 paper 글자를 accent/success/error 위에 놓는 조합만 허용 후보로 둔다. panel 위 강조색 작은 글자는 대비 검증 전 사용 금지. 투명도·hover·disabled 조합까지 본문 4.5:1, 경계 3:1 목표를 계산한 뒤 실제 캡처에서 확인한다. 위 HEX는 승인된 최종 팔레트가 아니다.

A는 꺾임 실루엣+‘A’, B는 막대+‘B’, 회전은 방향 화살표+0/90/180/270° 문장. 변경 예정 셀은 이중 테두리+삼각형, 목표는 ‘목표’ 제목과 고정 테두리, 미리보기는 ‘인쇄 후 · 아직 적용 안 됨’ 문장. 선택 체크와 키보드 포커스 화살표는 서로 다른 의미를 유지한다. 힌트는 물음표, 되돌리기는 굽은 화살표, 초기화는 원형 화살표+라벨로 구분한다. 아이콘만 있는 필수 명령은 만들지 않는다.

## 동작·피드백

| 사건 | 기본 애니메이션/문장 | 모션 축소 및 오디오 |
| --- | --- | --- |
| 선택/회전 | 선택 체크 즉시 변경, 도장만 90도 100ms 보간, 미리보기 즉시 새 상태 | 보간 없이 즉시; UI SFX 선택적 |
| 인쇄 | 논리 인쇄 즉시 1회, 도장 4px 눌림 120ms+잉크 정착 80ms, ‘인쇄 +1’ | 정적 갱신+문장, print SFX |
| 되돌리기 | 직전 상태 즉시 복원, 경계 120ms 강조, ‘한 번 되돌림’ | 정적 복원+문장, undo SFX |
| 오류/거부 | ‘완료 상태에서는 인쇄할 수 없음’ 등 구체적 원인, 2초 후 장식 강조 해제; 저장 오류 문장은 해결까지 유지 | 흔들림·점멸 없음, error SFX 1회 |
| 완료 | 체크가 180ms 나타남, 횟수·수동 다음 안내 유지. 마지막은 시험 끝 안내 | 즉시 체크·문장, complete SFX |

화면 흔들림·전체 섬광·파티클·반복 경고 없음. 연속 입력은 상태 순서대로 반영하며 이전 장식 애니메이션을 최종 상태로 정리한다. 애니메이션이 입력을 임의 합치거나 이력을 늘리지 않는다. 완료 SFX는 미해결→해결 전이에 한 번; 해결 후 undo하여 다시 풀면 새로운 전이에 재생한다. 완료 인쇄에서는 print와 complete를 겹쳐 재생하지 않고 complete로 대체한다.

## SFX 5종과 BGM 방향

새 구매·외부 다운로드·타사 샘플 없이 향후 표준 라이브러리 절차 합성 또는 담당자의 직접 제작을 제안한다. 권리는 제작 방식만으로 확인 완료가 되지 않으며 실물마다 출처·조건을 검토한다. MEDIA-001 최소 실물은 print/undo/complete 3종; UI/error 추가 2종과 BGM은 후속 선택 사항이다.

| ID | 길이 목표 | 소리 방향 | 기본 개별 게인 제안 |
| --- | --- | --- | --- |
| sfx_print | 0.15–0.25초 | 짧고 둔한 종이 도장, 날카로운 충격 줄임 | -6 dB |
| sfx_undo | 0.12–0.20초 | 부드럽게 풀리는 짧은 톤, 역재생 타사 샘플 금지 | -9 dB |
| sfx_complete | 0.45–0.70초 | 작고 안정된 2음, 승리 팡파르 없음 | -9 dB |
| sfx_ui | 0.04–0.08초 | 낮은 종이 접촉, 선택/확인 시만 | -12 dB |
| sfx_error | 0.12–0.20초 | 저자극 짧은 둔음, 경고 사이렌 없음 | -12 dB |

SFX WAV PCM 48kHz/16bit/mono, 끝·시작 5–10ms 페이드로 클릭 방지. 원본 목표 peak ≤-6 dBFS, DC offset 절댓값 ≤0.001, 포화 샘플 0. 수치는 제작/측정 기준이며 현재 측정한 값은 없다. UI/error 반복음만 최대 초당 5회로 제한하며 게임 입력 자체를 제한하지 않는다.

BGM은 보컬/강한 박자 없는 저밀도 종이 공방 분위기, 자체 작곡 60–90초 자연 루프 1곡을 향후 제안한다. 7일 시험에는 BGM 없이 SFX만으로 가능하며 침묵도 허용한다. 원본 WAV 48kHz/24bit/stereo, 배포 OGG Vorbis stereo 제안. 루프 접합 클릭·이상 정적·끝 공백 검수, 플레이를 재촉하는 템포 변화 없음. 음악 상업권리·파일 크기·청취 피로는 미검증이다.

볼륨은 master/SFX/BGM 각각 0–100%와 독립 음소거, 초기 80/70/30%. 각 값은 선형 진폭 배율(0은 완전 무음)이며 위 개별 게인과 곱해 적용한다. 원래 값을 보존한 음소거 해제, 설정 재시작 유지, master 음소거가 모두에 우선. 퍼즐 중 BGM은 연속, pause에서 0.5초에 걸쳐 추가 -6dB, 재개 시 복구; 효과음은 메뉴 확인음만 허용. 소리가 꺼져도 모든 상태와 오류는 텍스트/기호로 전달한다.

## 제작 후 검사 — 미실행

- 각 WAV 실제 채널/샘플레이트/비트·길이·peak/DC/포화 샘플 확인, 생성 스크립트·원본·해시 기록.
- master/SFX/BGM 모두 100%, 가능한 동시 재생과 빠른 조작에서 최종 믹스 peak ≤-1dBFS 및 포화 0 확인. 넘으면 원본/게인 조정; limiter만으로 숨기지 않음. 인코딩 후 true peak 확인 도구가 없으면 해당 항목 미검증.
- 실제 Windows 스피커/헤드폰에서 15분 사람 청취: 급격한 음량 차이·피로·클릭·루프 경계·되돌리기/완료 구분 기록. 수치 검사로 청취 품질을 인증하지 않음.
- 각 버스 0%/음소거 및 재시작 복원, 무음 상태 규칙 이해, 중복 인쇄에 따른 중복음 여부 확인.
- 720p/1080p 확대/흑백 캡처로 셀·기호·포커스·힌트 구분, 팔레트 실제 대비와 한글 렌더링 기록. 사람 아트 검토와 상업권리 승인은 별도 관문.

# PRODUCT-001 — C01 UI/UX 제작 설계안

작성일 2026-10-12 · 상태 PENDING_HUMAN_APPROVAL · 구현 및 화면 시험 미실행.
입력: [기존 감사](selection_audit.md), `../game/scripts/main.gd`, `game_state.gd`, `../game/docs/ITER-002_NOTES.md`, 저장소 PRODUCT-001 및 후속 task 명세. 새 후보 탐색·선정이나 상업 품질 판정이 아니다. 아래 수치는 제작 목표이며 검증 결과가 아니다.

## 범위와 상태 경계

7일 시험의 목표는 기존 두 퍼즐을 보존한 총 6퍼즐의 작은 수직 슬라이스다. 현재 코드는 두 퍼즐, 3×3 보드, A 꺾임/B 막대, 90도 회전, 미리보기, 인쇄, 되돌리기, 초기화와 수동 진행을 갖춘다. 타이틀·힌트·설정·저장·포커스 탐색은 후속 구현 대상이다. 위치 이동, 드래그, 셀 직접 편집, 새 규칙, 시간 제한, 별점·최소 수 인증을 추가하지 않는다. 미리보기·선택·회전은 턴을 소비하지 않으며 수락된 인쇄만 횟수와 이력을 늘린다.

전체 흐름: 시작→새 시험/이어하기→퍼즐↔일시정지→완료→수동 다음→마지막 완료→시작. 도움말·설정·힌트는 호출 화면을 기억한다. 초기화·진행 교체·종료 확인창은 취소가 기본 포커스다. 완료는 보드를 가리는 강제 모달 대신 완료 영역으로 표시하여 U/Z와 R 접근을 유지한다. 미사용 도장·다음·되돌리기 비활성 이유를 인접 문장에 남긴다.

마우스 클릭으로도 컨트롤 포커스를 표시한다. 포커스는 3px 이중 테두리+작은 화살표로 표시하며 선택 도장의 체크와 구분한다. 모달은 포커스를 내부에 가두고 닫힌 뒤 호출 위치를 복원한다. 컨트롤이 비활성/삭제되면 가장 가까운 유효 동작으로 이동한다. 현재 `FOCUS_NONE`은 후속 구현에서 변경·검증이 필요하다.

키 이벤트 처리 우선순위는 모달→포커스 컨트롤→미처리 퍼즐 단축키다. 한 물리 누름은 최대 한 명령을 발생시키고 echo 반복을 무시한다. 누름 후 해제한 별도 두 입력은 둘 다 게임 상태가 허용하면 유효하다. 시간 기반 합치기 금지. 버튼 신호 수뿐 아니라 인쇄 횟수·전체 보드·이력을 확인한다. 게임 상태가 먼저 확정되고 애니메이션은 결과를 표현한다.

## 720p·1080p와 접근성

기준 캔버스 1280×720, 1920×1080에서는 같은 계층을 유지하며 확대한다. 현재 최소 높이 840은 720p에 부적합한 설계 갭이며 실제 잘림을 관찰한 결과는 아니다. 창 최소 목표 960×540에서는 대체 배치를 쓰되 이번 필수 가독성 검사는 720p/1080p다.

720p 100% 기준 본문/버튼 20px 이상, 보조 18px 이상, 제목 28px 이상, 클릭 영역 최소 44×44px, 외곽 여백 24px. 1080p에서는 1.5배 기준 본문 30px 이상. 세 보드는 720p 기본에서 각 192px 정사각형, 1080p에서 288px를 목표로 한다. 셀 값은 최소 20px. 확대 시 글자만 키우고 보드를 잘라내지 않는다. 125/150%에서 세 보드를 같은 행에 맞출 수 없으면 현재+미리보기 상단/목표 하단 배치, 동작·설명 영역은 세로 스크롤로 재배치한다. 보드 전체와 제목은 항상 동시에 접근 가능하고 핵심 인쇄/되돌리기는 고정 하단 영역에 둔다. 포커스 이동 시 자동 스크롤, 가로 스크롤·말줄임으로 핵심 지시 숨김 금지.

본문 명암 대비 목표 4.5:1 이상, 셀/포커스/컨트롤 경계 3:1 이상. 팔레트 실제 대비는 별도 계산한다. 0=밝은 종이+‘0’, 1=어두운 잉크+‘1’; 바뀔 셀은 이중 테두리+모서리 삼각형, 선택은 체크+‘선택’, 불일치는 ×+개수, 완료는 체크+문장으로 표현한다. 색·음향만으로 정보를 전달하지 않는다. 텍스처는 문자와 셀 중앙을 피해 배치한다. 한국어/라틴/숫자 글리프와 폰트 권리는 미확정이다.

모션 축소 시 도장 이동·회전 보간·화면 흔들림·파티클을 없애고 즉시 최종 상태와 정적 문장을 표시한다. 기본도 번쩍임·흔들림 없음. 설정은 시작 전부터 접근 가능하며 재시작 후 유지한다. 스크린리더·게임패드 지원은 이번 시험에서 미구현/미검증으로 남기고 향후 별도 범위 판단한다.

## 저장·복원 계약

후속 구현 제안 경로 `user://c01_progress_v1.json`과 별도 설정 파일 `user://c01_settings_v1.json` (실제 파일 생성 없음). 진행은 schema_version, puzzle_set_version, puzzle_id, board 9개 0/1, selected_mask, rotation 0..3, moves, undo 전체 이력, 해결/해금 기록, 힌트 단계, 로컬 저장 시점으로 구성한다. 이름·계정·연락처는 수집하지 않는다. 해결 상태는 저장된 불리언 대신 보드/목표로 재판정한다. 이력의 보드/도장/회전/횟수 범위와 전이 일관성, 콘텐츠 버전을 검증한 후 한 번에 교체한다.

수락된 인쇄·되돌리기·초기화·다음 진행·힌트 공개 뒤 자동 저장하고 수동 저장도 제공한다. 임시 쓰기→재읽기 검증→교체 및 직전 유효 백업으로 중단 시 손상을 방지한다. 실패 시 현재 메모리 진행은 유지, ‘저장 실패: 재시도/저장 없이 계속’을 표시하고 성공 문구를 쓰지 않는다. 손상/새 버전은 조용히 초기화하지 않고 유효 백업 복원 또는 새 시험 선택을 제공한다. 복원 후 인쇄 횟수·선택·회전·undo와 완료/다음 활성 상태가 저장 직전과 일치해야 한다. 클라우드 저장은 범위 밖이다.

## 후속 수락 검사 — 모두 미실행

- 두 해상도 × 글자 3단계 × 모션 2단계에서 모든 화면 캡처: 핵심 정보 잘림 없음, 포커스 가시성, 대비·한국어 글리프 확인. Windows 배율 100/150%도 별도 확인.
- 마우스 없이 시작→두 퍼즐→완료→설정→저장→재시작→복원. 모달 탈출/복귀, 비활성 컨트롤과 마지막 진행 경계 확인.
- 인쇄 포커스에서 Space/Enter 1회, 2초 유지, 해제 후 별도 두 번 입력: 수락된 인쇄와 이력 증가가 일치하고 undo가 정확히 한 턴 복원. 다른 버튼 포커스에서는 그 버튼만 동작.
- 미리보기·힌트 열기/닫기는 보드/인쇄 횟수 불변. 완료 후 undo로 완료 안내 제거. 초기화 취소는 상태 불변.
- 정상·중단 쓰기·손상·호환 불가·쓰기 실패 저장 사례 및 전체 undo 이력 복원. 무음·흑백·모션 축소에서도 규칙과 결과를 이해할 수 있는지 사람 관찰.

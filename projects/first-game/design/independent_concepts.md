# PLAN-002 — 독립 신규 게임 콘셉트 탐색

작성일: 2026-10-12  
상태: 아이디어 탐색만 완료. 최종 게임 미선정, 개발 미착수, 시장 조사 및 플레이테스트 미실시.

## 1. 사용한 조건과 추정의 경계

조건은 Windows PC, 싱글플레이, 유료 Steam 출시 목표, 최대 12주 제작 목표, AAA·대규모·고사양 사실적 표현의 제작 부담 회피이다. 예산은 유연하지만 지출 예상은 표시하고 구매하지 않는다. 기존 기획 문서, 이전 프로젝트 디자인, 과거 대화, 저장소 밖의 자료는 읽거나 사용하지 않았다. 작업 규칙 외의 디자인 자료와 외부 시장 자료도 열람하지 않았다.

**이 문서의 제작 기간, 콘텐츠 수, 플레이 시간, 인력 가정, 비용 규모, 통과 수치, 플레이어 매력, 독창성, 엔진 선택, 최소 판매 가능 범위는 전부 추측 또는 제안 가설이다.** 수치는 측정 결과나 판매 보장이 아니다. 제안 엔진은 현재 버전·라이선스·배포 호환성을 조사한 결과가 아니며, 실제 선택 전 별도 확인이 필요하다.

비교를 위해 핵심 구현과 간단한 시각 자산을 담당할 수 있는 개발자 1명을 임시 가정한다. 주당 작업 가능 시간은 미확인이며 1주 프로토타입의 날짜는 달력일 기준의 제안 구간이다. 실제 인력·숙련도·기존 도구는 확인하지 않았으며 조건으로 확정하지 않는다. 기간에는 프로토타입, 콘텐츠, 품질 개선, 출시 후보 빌드 준비를 포함한다. Steam 심사와 계정 준비 등 외부 일정은 미확인이라 12주 안의 공개 출시를 약속할 수 없다.

아래의 '최소 판매 가능 범위'는 유료 제품 후보의 완결성을 위한 가설이다. 실제 구매 가치와 가격은 시장 조사와 사람의 검증 전에는 알 수 없다. 진행 저장, 재시작, 기본 설정, 조작 안내, 명확한 종료 지점을 공통 범위로 둔다. 자막과 텍스트 가독성, 색 이외의 구분 표시, 효과음·음악 개별 볼륨, 창/전체화면 전환도 계획한다. 추가 언어, 컨트롤러, Steam 연동 기능은 조사 후 사용자와 범위를 정한다.

**RESEARCH NOT DONE — 신뢰할 수 있는 시장 자료를 열람하지 않았다.** 경쟁작 이름, 판매량, 매출, 리뷰 통계, 현재 가격, 수요 규모를 제시하지 않는다. 아래의 흥미와 마케팅 판단은 아이디어 자체에서 도출한 가설이다.

## 3. 콘셉트 상세

### C01 — 음영 인쇄소

- **훅:** 판을 한 번 누를 때마다 밝고 어두운 칸이 뒤집힌다. 몇 번의 인쇄로 주문 도안을 정확히 만든다.
- **대상 플레이어 가설:** 시간 압박 없이 규칙을 이해하고 최소 수 풀이를 찾는 퍼즐 이용자.
- **순간별 코어 루프:** 목표 도안 확인 → 판 선택·회전 → 겹침 결과 미리보기 → 인쇄 → 차이를 읽고 실행 취소 또는 다음 인쇄 → 완성 후 더 짧은 풀이 도전.
- **핵심 메커니즘(3개):** 겹친 칸의 명암 반전, 회전 가능한 제한 판, 실행 취소와 최소 인쇄 수 도전.
- **표현·엔진 제안:** 2D, Godot. 도형과 종이 질감을 중심으로 한 정적 화면.
- **최소 판매 가능 범위 가설:** 4종 규칙 묶음, 수작업 검수 퍼즐 36개, 단계별 힌트, 자유 재도전. 첫 완료 2~3시간을 추측한다. 무한 생성이나 편집기는 제외한다.
- **1주 프로토타입 제안:** 1~2일에 반전·회전·정답 판정과 취소 구현, 3~4일에 6개 검증 가능한 퍼즐 제작, 5일에 미리보기·힌트 추가, 6일에 해답 재생 테스트, 7일에 처음 접한 사람의 풀이 관찰. 세션 목표는 15분.
- **위험:** 기술적으로 취소 후 상태 불일치와 대칭판 중복 처리가 문제다. 콘텐츠 측면에서는 같은 규칙의 반복, 풀이 폭증, 우연한 정답이 독창성과 만족을 약화할 수 있다. '겹침 퍼즐' 자체가 새로운 장르라는 주장은 하지 않는다.
- **자동 테스트 제안·통과 기준:** 모든 출시 퍼즐에 유효 해답 재생 1개 이상; 작은 보드의 전수 탐색으로 최소 수 표시 검증; 인쇄 후 취소 1,000개 생성 입력열에서 초기 상태 일치 100%; 회전 4회 후 원상 복귀. 프로토타입에서는 6개 퍼즐 모두 통과.
- **사람 플레이테스트 제안·통과 기준:** 처음 접하는 8명 중 6명 이상이 5분 안에 반전 규칙을 자기 말로 설명하고 첫 2개를 외부 도움 없이 해결; 5명 이상이 15분 후 추가 퍼즐을 자발적으로 선택; 2명 이하만 겹침 미리보기를 오해. 이는 소표본 진단용 추측 기준이다.
- **12주 범위 조정 제안:** 규칙 하나당 제작·검수 시간이 예상보다 크면 4종/36개에서 3종/24개로 줄이고 힌트와 완결된 학습 곡선을 유지한다. 24개가 반복적으로 느껴지면 판매 가능 가설을 기각하고 추가 제작을 자동 승인하지 않는다.
- **예상 지출 표시:** 선택적 종이 질감·효과음 라이선스, 스토어 캡슐 외주. 금액은 견적 전 미정이며 구매하지 않았다.

### C02 — 반동 청소부

- **훅:** 청소 포를 쏘는 반동으로 몸을 움직여, 떠다니는 쓰레기를 분쇄구로 밀어 넣는다.
- **대상 플레이어 가설:** 짧은 도전, 정밀 조준, 연쇄 성공과 점수 갱신을 좋아하는 액션 이용자.
- **순간별 코어 루프:** 쓰레기 배치와 위험물 읽기 → 이동 방향을 고려해 발사 → 반동으로 벽·위험물 회피 → 쓰레기 연쇄 투입 → 남은 연료로 다음 표적 결정 → 결과 비교·즉시 재시작.
- **핵심 메커니즘(3개):** 발사와 반동 이동의 결합, 질량별 밀림 차이, 연료 한도 안의 연쇄 점수.
- **표현·엔진 제안:** 2D 탑다운, Godot. 단순 물체 실루엣과 제한된 파티클.
- **최소 판매 가능 범위 가설:** 고정 아레나 12개, 쓰레기 3종, 위험물 2종, 점수 메달과 로컬 최고 기록. 첫 클리어 1~2시간, 기록 도전 시간은 미정. 보스·영구 업그레이드·온라인 순위표는 제외한다.
- **1주 프로토타입 제안:** 1~2일에 발사·반동·분쇄구 구현, 3~4일에 물체 2종과 아레나 3개, 5일에 점수·재시작, 6일에 충돌 경계 검사, 7일에 3판씩 조작 관찰.
- **위험:** 기술적으로 빠른 물체의 충돌 누락, 프레임 차이에 따른 감각 변화가 있다. 콘텐츠 측면에서는 판마다 비슷한 전략, 효과로 가려지는 위험물, 조작 피로가 문제다. 반동 이동을 단순한 익숙한 기믹으로 느낄 독창성 위험이 있다.
- **자동 테스트 제안·통과 기준:** 물체 100개 스트레스 장면의 경계 이탈 0건; 지정 고속 충돌 100회에서 누락 0건; 동일 고정 시간 간격·입력 재생의 점수 일치 100%; 연료 0 이하의 추가 발사 0건.
- **사람 플레이테스트 제안·통과 기준:** 8명 중 6명 이상이 3분 내 원하는 방향의 반동 이동을 연속 3회 수행; 5명 이상이 3판 안에 자기 첫 점수를 갱신; 6명 이상이 실패 원인을 입력·표적 선택으로 설명. 감각의 즐거움은 별도 인터뷰로 확인한다.
- **12주 범위 조정 제안:** 복합 물리 상호작용을 단순화하고 12개에서 8개 아레나로 축소한다. 점수 규칙과 재시작 품질은 유지한다. 2주째에도 조작 통제가 어렵다면 콘텐츠 양으로 덮지 않고 후보에서 제외한다.
- **예상 지출 표시:** 타격·분쇄 효과음, 선택적 이펙트 작업 외주. 금액 미정, 구매 없음.

### C03 — 세 개의 방패

- **훅:** 공격은 미리 보인다. 세 병사의 방패 방향과 자리를 바꿔 좁은 길을 지킨다.
- **대상 플레이어 가설:** 긴 육성보다 짧은 보드 전술과 예측 가능한 전투를 선호하는 이용자.
- **순간별 코어 루프:** 다음 적 행동 확인 → 병사 이동·방패 방향 선택 → 턴 실행 → 밀림과 피해 결과 읽기 → 진형 수정 → 제한 턴 동안 목표 보호.
- **핵심 메커니즘(3개):** 공격 의도 공개, 방향성 방패와 밀치기, 병사별 1행동 배분.
- **표현·엔진 제안:** 2D 격자 보드, Godot. 작은 말과 방향 화살표, 복잡한 전투 애니메이션 제외.
- **최소 판매 가능 범위 가설:** 병사 3명, 적 4종, 임무 18개, 선택 보너스 목표와 재도전. 첫 완료 3~4시간 추측. 성장 트리·절차적 캠페인·분기 스토리 제외.
- **1주 프로토타입 제안:** 1~2일에 턴·격자·방향 방어, 3~4일에 적 2종과 임무 3개, 5일에 의도 표시·턴 미리보기, 6일에 규칙 회귀 검사, 7일에 전술 설명과 재도전 관찰.
- **위험:** 기술적으로 밀침 연쇄 순서와 예고·실제 결과 불일치가 있다. 콘텐츠 측면에서는 사실상 단일 정답만 허용하는 임무와 병사 역할 중복이 문제다. 예고형 격자 전술의 기존 문법과 얼마나 다른지는 미확인이다.
- **자동 테스트 제안·통과 기준:** 방향 방어·측면 피격·장애물 밀침의 규칙 표 모든 사례 통과; 고정 입력열 100개에서 예고 피해와 실행 피해 일치 100%; 말 겹침·보드 이탈 0건; 임무별 성공 입력열 최소 1개 재생.
- **사람 플레이테스트 제안·통과 기준:** 8명 중 6명 이상이 첫 임무 후 5개 공격 사례 중 4개의 결과를 맞힘; 5명 이상이 실패 후 다른 진형을 시도; UI 오해로 발생한 피해가 관찰 피해의 20% 이하. 수치는 제안 기준이다.
- **12주 범위 조정 제안:** 18개 임무를 12개로 줄이고 적은 3종으로 제한한다. 난이도 곡선과 예고 정확성을 우선하며 새 지형·병사 추가를 금지한다. 전략 다양성이 안 나오면 선정 보류.
- **예상 지출 표시:** 병사·적 아이콘 또는 짧은 효과 애니메이션 외주, 효과음 라이선스. 금액 미정, 구매 없음.

### C04 — 순회 극단

- **훅:** 같은 공연도 어느 도시에서 언제 올리느냐에 따라 흥행과 배우의 피로가 달라진다.
- **대상 플레이어 가설:** 대규모 건설 없이 자원 배분, 일정 편성, 상황별 선택을 즐기는 경영 이용자.

- **핵심 메커니즘(3개):** 이동이 시간을 소비하는 노선 선택, 공연 수요와 배우 피로의 교환, 제한 예산의 장비·홍보 배분.

- **최소 판매 가능 범위 가설:** 도시 6개, 공연 4종, 배우 4명, 사건 12개, 20턴짜리 순회 1종과 난이도 2단계. 1회 45~60분 추측. 자유 건설·개별 배우 대화·실제 공연 조작 제외.

### C05 — 어긋난 증언

- **훅:** 모두가 조금씩 틀리게 기억한다. 거짓말과 착각을 구별해 잃어버린 물건의 이동 경로를 복원한다.
- **대상 플레이어 가설:** 읽기, 인물의 관점 비교, 증거를 설명하는 짧은 추리 이야기를 선호하는 이용자.
- **순간별 코어 루프:** 증언·시간표 읽기 → 증거 두 개 연결 → 질문 선택 → 수정된 진술 확인 → 물건의 이동 가설 제출 → 근거 피드백 확인.

- **최소 판매 가능 범위 가설:** 연결되는 사건 3개, 인물 5명, 증거 약 30개, 완결된 진상과 단계별 힌트. 2~3시간 추측. 자유 자연어 입력·거대한 분기·생성형 대화 제외.
- **1주 프로토타입 제안:** 1~2일에 증거 그래프·제출 판정, 3~4일에 인물 3명과 증거 8개의 사건 1개 집필, 5일에 질문·힌트, 6일에 잠금 조건 검사, 7일에 논리와 표현의 공정성 관찰.

- **예상 지출 표시:** 편집·교정, 선택적 인물 삽화 및 번역. 금액 미정, 구매 없음.

### C06 — 박자 직조

### C07 — 잠수정의 마지막 소리

### C08 — 부표 슬라럼

- **훅:** 물 위에서 미끄러지는 작은 보트를 몰아 부표를 올바른 쪽으로 통과한다. 가장 빠른 길은 직선이 아니다.
- **대상 플레이어 가설:** 경쟁 상대 없이 짧은 코스를 반복하며 조작 숙련과 기록 개선을 즐기는 이용자.
- **순간별 코어 루프:** 다음 부표와 코너 읽기 → 가속·선회·감속 → 관성에 맞춰 통과 → 분할 기록 확인 → 결승 후 자기 고스트와 재도전.
- **핵심 메커니즘(3개):** 단순화한 관성·선회, 방향 지정 부표 게이트, 자기 기록 고스트.
- **표현·엔진 제안:** 단순 3D, Godot. 고정 높은 추적 시점, 평평한 수면과 도형 섬. 사실적 유체 시뮬레이션 제외.
- **최소 판매 가능 범위 가설:** 보트 1종, 코스 8개, 튜토리얼, 코스별 메달·고스트·로컬 기록. 전체 코스 첫 완료 45~90분 추측, 숙련 반복 시간 미정. AI 상대·차량 커스터마이징·온라인 기록 제외.
- **1주 프로토타입 제안:** 1~2일에 가속·관성·선회, 3~4일에 30~60초 코스 2개와 부표 판정, 5일에 타이머·고스트, 6일에 게이트 경계·기록 검사, 7일에 5회 반복과 조작 개선 관찰.

## 4. 검증 계획의 공통 해석

위의 테스트는 **향후 실행할 제안이며 이번 작업에서 실행하지 않았다.** 자동 테스트는 규칙의 정확성·재현성과 진행 가능성을 확인한다. 재미, 공포, 음악의 매력, 구매 의사는 자동 테스트로 입증하지 않는다.

사람 테스트의 기본 계획은 각 후보에 관심이 있는 처음 접하는 성인 8명의 개별 관찰이다. 모집 가능성과 비용도 미확인이다. 먼저 조작 안내만 제공하고, 진행 중 유도 설명 없이 선택·막힘·재시도·소요 시간을 기록한다. 종료 후 실패 원인, 기억한 차별점, 계속할 이유를 묻는다. 도움 제공 여부와 미완료·중도 종료를 함께 기록하며 좋은 반응만 골라 쓰지 않는다.

관찰 기준은 프로토타입 가설의 진단 기준이고 상업적 합격 판정이 아니다. 8명은 시장을 대표하지 않는다. 기준 미달이면 원인을 설명하고 기존 기준을 유지한 재검증을 제안한다. 재미가 없다는 신호를 콘텐츠 수 증가나 기준 완화로 가리지 않는다. 수정 후 재검증과 본 제작은 사용자 승인 이후에만 진행한다.

성능 기준은 테스트용 Windows PC의 사양을 기록한 뒤 합의한다. 잠정 목표는 목표 PC에서 1080p 60fps이며 아직 측정하지 않았다. 출시 후보 단계의 공통 자동 검사는 저장 왕복·잘못된 저장의 안내·입력 재설정·일시정지·씬 재진입 검사, 사람 검사는 설치 또는 압축 해제 후 첫 실행·창 전환·오디오 설정·30분 진행·종료 후 이어하기로 제안한다. 현재 코드는 작성하지 않았다.

## 5. 비교 기준과 잠정 후보 3개

최종 선정은 하지 않는다. 아래는 **조사와 사용자 검토를 먼저 받을 잠정 후보 3개**이다. 프로토타입 제작 승인이 아니며 실제 개발 우선순위도 확정하지 않는다.

비교 기준은 동일하게 적용했다.

1. **플레이어 매력 가설:** 어떤 사람이 무엇 때문에 다시 시도할지 구체적으로 설명할 수 있는가.
2. **독창성 위험:** 테마 교체만 남거나 기존 장르의 익숙한 규칙을 반복할 가능성이 얼마나 큰가. 경쟁작 조사가 없으므로 실제 독창성은 미확인이다.
3. **제작 가능성:** 구현·콘텐츠·시청각·권리 의존성을 12주 가정 안에서 줄일 수 있는가.
4. **검증 가능성:** 1주 안에 핵심 경험을 만들고 성공·실패 원인을 측정할 수 있는가.
5. **마케팅 명료성:** 짧은 문장과 10초 내외 화면 예시로 실제 플레이를 설명할 수 있는가.

숫자 점수는 사용하지 않았다. 정성 비교도 증거가 아니라 설계 관점의 추측이며 판매량이나 재미를 예측하지 않는다.

세 후보가 모두 조사 또는 검증에서 약하면 보류 후보를 다시 검토하거나 신규 탐색을 요청한다. 이번 비교만으로 선택·구매·개발을 시작하지 않는다.

## 6. 12주 제작 가설과 중단 지점

아래는 **사용자가 게임과 후속 작업을 승인한 뒤 사용할 수 있는 일정 초안**이다. 이번 작업에서 착수하지 않았다.

## 7. MARKET-RESEARCH-TO-DO

**RESEARCH NOT DONE.** 아래 모든 항목은 미실시이며 자료·관찰·추정의 열을 분리해 기록해야 한다. 조사 계획은 게임 선택이나 판매 가능성 확인을 의미하지 않는다.

- [ ] **Steam 경쟁작:** 각 잠정 후보의 같은 주 활동을 가진 유료 싱글플레이 Windows 게임 5개 이상을 검색한다. '작은 규모의 최근 출시작'과 '이미 알려진 작품'을 나눠 성공 사례 편향을 줄인다. 잠정 검색어는 반전·겹침 퍼즐, 소규모 경영·일정, 수상·슬라럼·타임어택의 한국어/영어 표현이다. 실제 제목·URL·열람일·출시일·태그·설명·범위·현재 가격을 확인한 자료 그대로 기록한다.

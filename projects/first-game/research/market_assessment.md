# ASSESS-001 — 상업적 위험과 다음 프로토타입 실험의 독립 평가

작성일: 2026-10-12. 상태: **추가 조사 요구 / 상품성·최종 선정 판단 보류**. 문서 평가만 수행했으며 아래 실험은 미실시 계획이다.

## 1. 결론과 근거의 경계

**세 후보 모두 상품성 판단에는 insufficient_evidence이다.** 자료는 규칙 중복을 논의할 단서를 제공하지만 동일 조건의 가격, 최근 리뷰 본문, 구매 가치 반응, 실제 조작·풀이 경험을 제공하지 않는다. 판매량·매출도 모두 확인 불가다. 경쟁작의 존재는 수요 규모나 이 프로젝트의 수익 가능성을 입증하지 않는다. 숫자 점수, 가중 순위, 성공 확률, 리뷰→판매량 환산으로 공백을 채우지 않는다. [자료 근거: 시장 보고서의 ‘분량·가격·리뷰·판매 근거의 상태’](steam_market_report.md)

한 후보의 실험 순서를 정해야 한다면 **C01을 잠정 실험 후보**로 제안한다. 작은 보드의 해답·취소 검사와 퍼즐 제작 시간 측정으로 실패 원인을 좁힐 수 있다는 제작 검증 가설 때문이다. 이는 시장 우위 판단이나 제작 승인과 다르다. C04와 C08도 각각 독립된 1주 실험으로 비교하고, C01이 실패하면 차순위가 자동 선정되는 것이 아니라 조사·선정이 다시 보류된다. **미검증 모델 판단**; 설계 근거: [콘셉트 문서 §3 C01·C04·C08, §4–6](../design/independent_concepts.md).

### 사용한 입력과 표기

기획·시장 판단 입력은 아래 세 파일뿐이다. PLAN-001, 외부 개인 폴더, 이전 대화·프로젝트, 별도 시장 자료를 읽거나 사용하지 않았다. 새로운 웹 검색·상점 열람은 수행하지 않았다. 작업 규칙은 저장소 AGENTS.md와 이번 사용자 지시를 적용했다.

- [independent_concepts.md](../design/independent_concepts.md): 후보의 규칙, 범위, 위험, 실험 기준. 제작 기간·분량·플레이 시간·엔진·비용·매력은 원문부터 미검증 가설이다.
- [steam_competitors.json](steam_competitors.json): 후보별 비교작, URL, evidence_note, evidence_gaps.
- [steam_market_report.md](steam_market_report.md): 2026-10-12의 검색·공식 상점 텍스트 관찰 기록과 확인 한계.

이 보고서의 **관찰 사실**은 ‘입력 자료가 해당 내용을 기록하고 있다’는 뜻이다. 외부 링크는 입력이 제시한 원출처이며 이번 평가에서 재확인하지 않았다. 상점 설명은 개발자 기능 주장이고, 플레이 검증 결과가 아니다. **모델 판단 / 미검증**은 자료에서 도출한 위험·차별화·상품성 가설이다. **실험 제안 / 미검증**의 수치는 사전 진단 기준이며 시장 점수가 아니다.

시장 보고서의 ‘승인된 문서’라는 표현을 최종 콘셉트 승인으로 해석하지 않는다. 콘셉트 원문은 최종 미선정·프로토타입 제작 미승인으로 명시한다. 이 평가는 미선정 상태를 유지한다. [문서 상태 근거](../design/independent_concepts.md)

**모델 판단 / 미검증:** 알려진 대형·확장된 작품과 작은 신규 제품을 혼합하면 콘텐츠 양과 가격 기대를 잘못 추정할 수 있다. ‘비슷한 작품이 적다’와 ‘경쟁이 약하다’는 결론도 검색 누락·동의어·인접 장르를 확인하기 전에는 낼 수 없다. 원문에서 요구한 후보별 5개 이상 조사도 현재 3·3·4개 링크만으로 완료된 것이 아니다. 예정작·인접작을 직접 경쟁작처럼 합산하지 않는다. [조사 계획 §7](../design/independent_concepts.md), [실제 비교 범위](steam_competitors.json)

### 모델 판단 / 미검증: 차별화·범위·상품성

- **명확히 설명할 차별화 가설:** ‘배치해서 모양을 만드는 경험’과 비교해, 제한 판을 회전해 현재 보드를 뒤집고 목표까지 필요한 인쇄 수를 줄이는 결정을 보여 준다. 종이·인쇄소 테마와 취소 기능만으로 경쟁 우위를 주장할 수는 없다. VOI에 해당 조합이 없는지는 미확인이다. 설계: [C01](../design/independent_concepts.md); 중복: [VOI](https://store.steampowered.com/app/545690/).
- **독립 반증 질문:** 판의 효과가 독립적인 XOR 마스크이고 중간 상태 제약이 없다면, 인쇄 순서 변경이 최종 결과를 바꾸지 않고 같은 판을 두 번 쓰면 상쇄될 가능성을 검사해야 한다. 단계적 인쇄가 화면 표현의 차이만 남을 수 있다는 조건부 가설이며 실제 판 이동·사용 제한 규칙은 아직 충분히 정의되지 않았다. **미검증 모델 판단**; [명암 반전·제한 판 설계](../design/independent_concepts.md). 순서가 교환 가능하다는 이유만으로 퍼즐 가치가 없다고 단정하지도 않는다. 판 선택·회전·최소 수 판단이 다른 경험인지 관찰한다.
- **범위 위험:** 원문의 4종/36개·2~3시간은 제품 가설이다. 규칙 구현보다 해답 보장, 최소 수 탐색, 힌트 집필, 난이도·풀이 다양성 검수가 병목일 수 있다. 3종/24개 축소도 유료 완결성을 보장하지 않는다. 원문의 두 범위를 유지하고 검수 시간을 측정한다. [범위와 축소안](../design/independent_concepts.md); **미검증 모델 판단**.
- **상품성 가설:** 짧은 목표→인쇄→완성 화면으로 주 활동을 설명할 가능성은 있다. 반면 퍼즐을 푸는 만족과 더 구매할 이유는 별개이며, 적은 퍼즐 수·비슷한 풀이가 가치 불만을 만들지는 리뷰와 사람 검증이 필요하다. 36개를 .projekt의 60/120개와 단순 비교해 가격이나 가치로 환산하지 않는다. **미검증**; [설계](../design/independent_concepts.md), [.projekt](https://store.steampowered.com/app/759000/).

판정: 핵심 연산의 신규성은 주장 불가. 전체 조합의 차별성과 구매 가치는 **insufficient_evidence / 보류**.

### 모델 판단 / 미검증: 차별화·범위·상품성

- **명확히 설명할 차별화 가설:** ‘지금 공연할 수익’과 ‘이동에 쓸 시간·쉬어 회복할 피로’를 같은 일정 선택의 기회비용으로 보여 준다. 카드 대결·턴제 전투를 제외한 장부 중심의 판단 단위는 설계상 설명 가능하지만, 경쟁작에 일정·피로 조합이 없는지는 미확인이다. 극단 테마나 장비·홍보만으로 차별화됐다고 평가하지 않는다. [설계 C04](../design/independent_concepts.md), [Circus](https://store.steampowered.com/app/1433860/), [Electrique](https://store.steampowered.com/app/1666250/), [Rock God Tycoon](https://store.steampowered.com/app/410840/).
- **독립 반증 질문:** 성공 노선 두 개가 존재해도 하나가 모든 상황에서 더 좋은 결과를 내면 의미 있는 전략 다양성이 아니다. 수요·초기 피로가 바뀔 때 일정 선택의 근거와 유리한 노선도 바뀌는지 검사한다. 단일 최적 일정, 홍보의 상시 우월·무효, 결과 계산의 불투명성이 핵심 위험이다. **미검증 모델 판단**; [원문의 선택 트리·단일 전략 위험](../design/independent_concepts.md).
- **범위 위험:** 도시 6개·공연 4종·배우 4명·사건 12개·20턴·난이도 2단계, 45~60분은 원문 가설이다. 숫자 상호작용과 UI 설명 검수가 자산 절약분을 소모할 수 있다. 도시 4개·사건 8개·16턴 축소 후에도 수요·피로·노선의 교환이 성립해야 한다. 실제 공연 조작·대사·전투를 추가해 약한 선택을 덮지 않는다. **미검증 모델 판단**; [범위 및 축소안](../design/independent_concepts.md).
- **상품성 가설:** 짧은 순회 운영 경험이 경영 이용자에게 매력적일 수 있으나, 정적 무대와 장부가 표현·깊이 기대를 충족할지는 확인 불가다. 소개에 기록된 90개 도시·200개 초과 카드 또는 76개 도시를 C04의 제작비·완주 시간·필수 출시량으로 환산하지 않는다. **미검증**; [Circus](https://store.steampowered.com/app/1433860/), [Rock God Tycoon](https://store.steampowered.com/app/410840/), [분량 한계](steam_market_report.md).

판정: 공연 운영과 예산 배분의 중복은 분명한 단서가 있다. 일정·피로 중심의 고유한 선택 및 상품성은 **insufficient_evidence / 보류**.

### 모델 판단 / 미검증: 차별화·범위·상품성

- **명확히 설명할 차별화 가설:** 단순 관성으로 방향 게이트를 통과하고, 오프라인 자기 고스트·분할 기록에서 한 코너의 개선 이유를 읽는 짧은 반복 경험. 방향 부표·고스트 각각의 신규성은 주장할 수 없다. 경쟁작의 자기 고스트 부재, C08의 더 나은 조작감·빠른 재시작도 확인되지 않았다. [설계 C08](../design/independent_concepts.md), [Speedboats](https://store.steampowered.com/app/501090/), [Riptide GP2](https://store.steampowered.com/app/257790/), [Absolute Drift](https://store.steampowered.com/app/320140/).
- **독립 반증 질문:** 다섯 번 반복해 기록이 개선돼도 단순한 코스 암기일 수 있고 즐거움·자발적 재도전의 증거가 아닐 수 있다. 고스트를 보고 개선 이유를 설명하는지와 테스트 종료 뒤 다시 달리기를 선택하는지를 별도로 기록한다. 고스트 표시 전후 차이도 순서·학습 효과를 통제하지 않으면 인과 근거로 사용하지 않는다. **미검증 모델 판단**; [원문 기록 개선·고스트 기준](../design/independent_concepts.md).
- **범위 위험:** 보트 1종·코스 8개·첫 완료 45~90분은 가설이다. 고정 카메라 가독성·충돌/게이트·프레임 차이·고스트 정확성·코스별 선회 차이가 동시에 필요하다. 6개 코스·배경 1묶음으로 줄여도 조작과 판정 품질은 유지한다. 사실적 수면·온라인·AI·차량 꾸미기를 추가하지 않는다. **미검증 모델 판단**; [범위·축소안](../design/independent_concepts.md).
- **상품성 가설:** 코너와 고스트의 시각적 차이가 짧은 영상에서 활동을 설명할 가능성은 있지만, 짧은 첫 완료 시간을 숙련 반복이 충분히 보완할지는 미검증이다. 60개 초과 이벤트를 고유 코스 수로, 예정작의 15개 초과 트랙을 실제 출시량으로 바꾸지 않는다. **미검증**; [Riptide GP2](https://store.steampowered.com/app/257790/), [Wavecraft Legends](https://store.steampowered.com/app/4492170/), [분량 한계](steam_market_report.md).

판정: 방향 부표·타임어택·기록 비교의 기존 문법이 확인된 단서다. 조합의 경험 차이와 유료 반복 가치는 **insufficient_evidence / 보류**.

## 6. 후속 1주 프로토타입 비교 계획 — 아직 실행하지 않음

다음은 사용자 검토용 **실험 제안 / 미검증**이다. 실제 개발·모집·플레이테스트는 이번 작업에 포함되지 않는다. 원문의 개발자 1명은 임시 가정이며 가용 시간·숙련도·도구·모집 가능성도 미확인이다. **각 후보에 1주씩 별도 실험 창**을 배정하는 계획이다. 세 후보를 한 사람이 같은 1주에 모두 완성한다는 약속이 아니다. 하나만 허용되면 C01만 먼저 진단하고, C04·C08은 미검증 상태로 남긴다. [일정·인력 가정과 원문 실험](../design/independent_concepts.md)

### 공통 설계와 비교 방법

- 시작 전 실제 주간 가용 시간, 테스트 Windows PC·입력 장치, 사용할 기존 도구, 모집 가능 인원을 기록한다. 핵심 루프와 사람 관찰이 한 주에 불가능하면 범위를 임의로 넓히거나 통과 조건을 낮추지 않고 일정 판단을 보류한다.
- 원문대로 관심 있는 처음 접하는 성인 **후보별 8명**을 목표로 한다. 안내 후 유도 도움 없이 관찰하고 도움·미완료·중도 종료·막힘·자발적 재시도를 모두 기록한다. 8명은 시장 대표 표본이 아니다. 8명을 채우지 못하면 아래 인원 기준을 달성한 것으로 간주하지 않는다. 개인정보는 저장소에 기록하지 않는다. [모집·해석 기준 §4](../design/independent_concepts.md)
- 장르 경험과 입력 장치 차이를 기록한다. 여러 후보를 체험하는 참여자는 후보 순서를 교차 배치하고, 각 후보를 처음 접하는지 확인한다. 서로 다른 이용자군의 반응을 합쳐 인기 순위를 만들지 않는다. **추가 방법 제안 / 미검증**.
- 공통 기록은 규칙 이해, 실패 원인 설명, 자발적 지속, 기억한 차별점, 핵심 콘텐츠 1단위의 제작·검수 시간이다. 완주 속도·퍼즐 수·경영 수익을 같은 점수로 환산하지 않는다. 기술 정확성, 경험, 시장 근거를 각각 검토한다. **추가 방법 제안 / 미검증**.
- 실제 플레이를 보여 주는 짧은 설명/화면을 보고 주 활동을 자기 말로 설명하는지 묻는다. ‘인쇄소/극단/보트’라는 테마 답변과 규칙 설명을 구분한다. 구매 의향·가격 기대는 별도 정성 기록이며 실제 구매로 취급하지 않는다. 경쟁작 대비 새롭다는 응답도 해당 작품 체험 여부 없이는 독창성 증거가 아니다. [마케팅·이용자 조사 계획 §7](../design/independent_concepts.md); **미검증 방법 제안**.

### 실패·중단 및 재평가 기준

- **공통 실패:** 기술 기준이 하나라도 실패하면 그 빌드를 경험 비교의 신뢰 가능한 자료로 취급하지 않는다. 사람 기준 미달·관찰 누락·모집 미달을 통과로 기록하지 않는다. 결함·원인·실제 시간을 보고하고, 기준을 유지한 수정 실험만 후속 검토한다. 핵심 루프가 주말까지 성립하지 않거나 범위 확대가 필요하면 본 제작 전환을 중단한다. [원문 검증·중단 원칙](../design/independent_concepts.md)
- **C01 추가 중단 가설:** 제한 판/회전/최소 수가 다른 사고나 선택을 만들지 않고 퍼즐 6개가 같은 풀이 반복으로 관찰되면 차별화 가설 실패로 기록한다. 순서 교환성 자체를 실패로 삼지 않는다. 검수 시간이 원문 36개 또는 축소 24개의 제작·QA 여유를 충족하지 못하거나 24개가 반복적으로 느껴지면 유료 범위 판단을 보류한다. **추가 모델 기준 / 미검증**; [원문 C01 축소·중단](../design/independent_concepts.md).
- **C04 추가 중단 가설:** 성공 노선 두 개가 있어도 한 일정이 검토한 모든 수요·피로 조건에서 우월하면 전략 다양성 가설 실패다. 결과 내역을 보아도 선택 이유를 설명하지 못하거나 수요/피로/노선을 없애야 일정이 맞으면 중단한다. 대사·삽화·사건 추가로 보완하지 않는다. **추가 모델 기준 / 미검증**; [원문 C04](../design/independent_concepts.md).
- **C08 추가 중단 가설:** 두 코스의 다른 선회 이유를 관찰에서 구별하지 못하면 코스 다양성 가설을 보류한다. 기록 개선만 있고 고스트의 도움·자발적 반복 근거가 없으면 구매 가치 입증으로 사용하지 않는다. 조작 불능감 기준 미달 상태에서 코스를 늘리지 않는다. **추가 모델 기준 / 미검증**; [원문 C08](../design/independent_concepts.md).
- **진행 조건:** 기술·사람 기준이 충족돼도 다음 단계는 제작 시간 재산정과 추가 시장 자료 검토이다. 구현·콘텐츠·설정/저장·Windows QA·소개 자료에 필요한 실제 시간과 미확인 작업을 함께 적고 12주 가능 여부를 재평가한다. 세 후보 모두 약하면 전부 보류하며 반드시 하나를 선택하지 않는다. 최종 게임 선정은 사용자 판단으로 남긴다. [공통 일정·선정 원칙 §5–6](../design/independent_concepts.md)

## 8. 실제 수행한 문서 검증과 미실시 항목

저장 후 파일을 다시 읽어 UTF-8 엄격 디코딩과 저장 내용 일치를 확인했다. 입력 JSON을 파싱하고 후보 ID·근거 상태·출처 URL을 대조했다. 보고서의 Steam URL이 입력 JSON의 채택 URL에 모두 포함되는지, 10개 채택 URL이 모두 등장하는지, 로컬 문서 링크가 세 입력에 한정되는지 검사했다. 세 후보의 관찰/판단·insufficient_evidence·1주 계획·실패/중단·새 데이터 항목의 존재를 확인했다. 세 입력 파일의 SHA-256이 작성 전후 동일한지와 Git 상태상 추가 파일이 market_assessment.md 하나인지 확인했다. 이는 문서·변경 범위 검사이며 시장 검증이 아니다.

초기 셸 호출은 도구 초기화 오류로 실패했다. 파일 입출력·내용 검사는 Node 도구를 사용했고 Git 상태는 Node에서 git을 호출해 확인했다. 저장소 테스트 실행기, 게임 자동 테스트, Windows 빌드·성능 측정, 사람 플레이테스트, 새 웹 조사·URL 접근 검증은 수행하지 않았다. 최종 게임 확정·실제 개발·의존성 설치·구매·외부 연락·게시·출시·Git 커밋도 수행하지 않았다.

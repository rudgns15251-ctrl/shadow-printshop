# MEDIA-001 — C01 종이·도장 / SFX 시범 실물

## 코드·자산 산출물

기존 게임 파일 33개를 모두 보존하고 선택 실행 장면 `res://media_preview.tscn`을 추가했다. 프로젝트 기본 실행 장면은 그대로다. Godot 편집기에서 media_preview.tscn을 열고 F6으로 실행하거나, 준비된 Godot 4 환경에서 다음 명령으로 시범 게임을 실행한다(이번에는 실행하지 못함).

```text
godot --path projects/first-game/game res://media_preview.tscn
```

이 장면은 `scripts/media_preview.gd`를 통해 기존 `scripts/main.gd`를 상속한다. 원래 UI, 입력 처리, 퍼즐, 상태 변경 및 완료 안내를 호출하고 그 결과를 관찰한다. 인쇄 횟수가 증가한 경우에만 인쇄 효과, 이력 길이가 감소한 경우에만 취소 효과를 재생한다. 성공한 인쇄가 완료 상태를 만들 때 완료 효과를 추가한다. 완료 후 거부된 인쇄, 빈 이력의 취소에는 효과가 없다. 초기화·다음 이동에는 SFX를 추가하지 않았다. PROTO-002의 별도 mech 장면 및 데이터도 그대로다.

- `assets/art/stamp_preview.svg`: 240×96 종이·접힌 모서리·잉크 도장 UI 한 세트. 외부 이미지·폰트·링크 없이 직접 작성한 SVG 도형이다. 시범 장면 하단에 표시하며 게임 보드의 0/1 색 의미는 유지한다.
- `scripts/media_preview.gd`: 장식 도장의 축소→복원(0.22초) 및 잉크 색→원색(0.30초) Tween 반응. 연속 입력은 이전 Tween을 중단하고 새 반응을 시작한다. 애니메이션이 게임 입력을 지연시키거나 상태를 변경하지 않는다.
- `tools/generate_sfx.py`: Python 표준 라이브러리의 math/random/struct/wave 등으로 44,100 Hz, 모노, signed 16-bit PCM을 합성한다. 고정 시드 잡음, 사인파, 감쇠·시작/끝 페이드를 사용했다. 외부 음원·샘플·라이브러리·다운로드·유료 호출은 사용하지 않았다.
- 하단의 print/undo/complete별 슬라이더(0–100%, 기본 60%)와 mute 체크박스: 각 AudioStreamPlayer 음량을 독립 조절한다. 0 또는 mute는 현재 재생을 중지하고 이후 재생을 막는다. 해제는 다음 유효 동작부터 적용한다. 설정은 세션 내에서만 유지한다. 키보드 게임 조작의 포커스를 바꾸지 않도록 새 조절 UI는 마우스로 조작한다.

## 실제 생성된 WAV와 연동 위치

다음 경로는 game/ 기준이다. WAV는 UTF-8 문서가 아닌 실제 바이너리이며 acceptance 문서 목록에 추가하지 않았다.

| 경로 | 길이 / 프레임 | 파일 바이트 | 최대 절대 PCM 샘플 | 게임에서 들리는 위치 |
| --- | --- | --- | --- | --- |
| assets/audio/print.wav | 0.18초 / 7938 | 15920 | 16949 | Space/Enter 또는 PRINT 버튼으로 성공한 인쇄 직후 |
| assets/audio/undo.wav | 0.24초 / 10584 | 21212 | 9393 | U/Z 또는 undo 버튼으로 이력이 실제 감소한 직후 |
| assets/audio/complete.wav | 0.55초 / 24255 | 48554 | 10924 | 각 퍼즐을 완료한 성공 인쇄 직후, 인쇄 효과와 함께 |

SHA-256 실제 측정:

```text
print.wav    6098ea0ce0b8e7dd96e9a883c434c5ae0ac07caa5e26b2c9feed13dc1c4d3b36
undo.wav     99bd6593048131123ef8a326735c922f2d2259ee643c51c699175abc5898f9ba
complete.wav 32591beb62132a3324bef3c728335e037c1d2936aebcda19c17b5770511188b3
```

실물 재확인 방법: 저장된 WAV를 Python `wave.open`으로 열어 채널 1, 샘플 폭 2, 샘플레이트 44100 및 위 프레임 수를 확인하고 SHA-256을 비교한다. 생성 명령은 아래와 같으며 동일 경로의 시범 WAV를 재생성한다. 이번에 실제 실행했다.

```text
python3 projects/first-game/game/tools/generate_sfx.py
```

## 이번에 실제 수행한 자체 검증

Python 3.14.4에서 생성 스크립트 실행 종료 코드 0. 각 WAV를 다시 읽고 합성한 PCM과 바이트 일치를 확인했다. 별도 검증에서 합성 함수를 다시 호출해 저장된 모든 PCM 샘플과 일치함을 확인했다. 세 파일의 헤더·프레임 수·바이트 수·최대 절대 샘플 및 위 해시를 측정했다. 개별 PCM 최대치는 32767 미만이다. 이것은 개별 파일의 수치 확인이며 게임 혼합 출력·장치의 클리핑이나 실제 청취 품질 인증이 아니다.

SVG는 Python ElementTree XML 파싱 성공. Python 생성 소스는 compile 구문 검사 성공. 작업 시작 시 게임 폴더 내 기존 33개 파일의 SHA-256을 임시 기록한 뒤 전부 재비교하여 동일함을 확인했다. 기존 보호 테스트·VALIDATION.json·기존 문서도 수정하지 않았다. Git·하네스·AGENTS.md·다른 프로젝트를 읽거나 변경하지 않았고 네트워크·설치·커밋을 수행하지 않았다.

Godot 실행 파일을 `command -v godot` 및 `command -v godot4`로 확인했으나 발견하지 못했다. Godot 파싱·SVG/WAV 임포트·시범 장면 실행·기존 smoke/regression은 실행하지 못했다. 이 기록은 자체 정적/파일 검증이며 독립 QA 또는 사람 플레이테스트 통과 기록이 아니다.

## 미검증 및 사람 승인 시 확인

Godot 4에서 시범 장면의 리소스 임포트/스크립트 오류, 하단 배치·DPI·창 크기별 겹침, 마우스 조절 UI를 확인해야 한다. 두 퍼즐에서 인쇄→취소→재인쇄→완료→수동 다음 이동을 수행하고 기존 보드·횟수·이력·완료 안내가 유지되는지 확인해야 한다. 거부된 인쇄/취소의 무음, 초기화의 무음, 각 SFX만 음소거/해제 및 0/60/100% 조절을 직접 청취한다. 완료 시 동시 출력·빠른 연속 입력·음소거 중 재생 종료도 확인한다. 실제 Windows 입력, 청취 품질·불쾌한 고역·팝·혼합 클리핑은 미검증이다. 기본 실행 장면으로 채택하려면 별도 통합 검토가 필요하다.

직접 작성한 도형과 자체 절차 합성으로 만들었으며 타사 자산 라이선스를 취득했다고 주장하지 않는다. 제3자 상업적 권리 검토는 완료되지 않았다. 배포 전 사람 담당자가 표현의 유사성·상표/디자인 충돌, 절차 생성 산출물의 권리 취급, 엔진 및 배포 구성요소의 라이선스·표시 의무를 별도로 검토해야 한다. 이 시범은 최종 콘셉트·상업 출시·공개 배포 승인 또는 시장성 검증을 의미하지 않는다.
